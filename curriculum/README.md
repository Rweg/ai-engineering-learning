# Curriculum

This curriculum is organized around practical AI engineering evidence: each module should produce a small artifact, code example, checklist, or writeup.

## Module 1: RAG Foundations

Learn:

- chunking strategies
- embedding models
- vector databases
- hybrid search
- prompt assembly
- grounded generation

Produce:

- RAG notebook or small app using public documents
- retrieval evaluation notes
- failure-mode checklist

## Module 2: Azure AI Foundry

Learn:

- model catalog
- playground workflows
- deployments
- evaluation concepts
- API usage

Produce:

- deployment notes
- model comparison table
- cost and latency notes

## Module 3: Azure OpenAI

Learn:

- model deployment
- prompt engineering
- token management
- streaming
- model selection

Produce:

- prompt evaluation matrix
- streaming API demo
- token/cost calculator

## Module 4: Azure AI Search

Learn:

- indexes
- vector fields
- HNSW
- hybrid search
- semantic ranking
- RAG integration

Produce:

- search index design
- retrieval quality report

## Module 5: MCP

Learn:

- tools
- resources
- JSON schemas
- secure context access
- integration boundaries

Produce:

- tiny MCP-style tool design
- security boundary notes

## Module 6: Agent Systems

Learn:

- tool calling
- memory
- planning
- execution
- evaluation
- frameworks such as LangGraph or OpenAI Agents

Produce:

- agent design doc
- evaluation checklist

## Module 7: Production Monitoring

Learn:

- latency
- p95 and p99
- token usage
- cost
- hallucination rate
- evaluation datasets
- observability

Produce:

- monitoring dashboard sketch
- alerting plan

## Module 8: Docker

Learn:

- Dockerfile
- docker build
- docker run
- containerized APIs

Produce:

- containerized model-serving or RAG API

## Module 9: CI/CD

Learn:

- GitHub Actions
- testing
- deployment
- gated releases

Produce:

- basic CI workflow for tests and linting

## Module 10: Fine-Tuning Decision Framework

Learn:

- when prompting is enough
- when RAG is appropriate
- when fine-tuning makes sense
- when not to train

Produce:

- decision tree
- applied comparison across three use cases

## Module 11: Capstone

Build:

- synthetic health-data readiness and triage copilot

Produce:

- portfolio writeup
- model card
- data card
- runbook
- evaluation report
