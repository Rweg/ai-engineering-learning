# Health AI Specialization

This lane prepares for AI engineering roles that require production systems, responsible deployment, interoperability, and model validation in health-system contexts.

Use only public, synthetic, or self-created data.

## 1. Digital Health Systems

Learn:

- EMR, HMIS, and LMIS concepts
- API-first integration
- batch and real-time inference patterns
- operational decision-support workflows

Artifact:

- one-page architecture sketch for a synthetic health AI workflow

## 2. HL7 and FHIR Basics

Learn:

- resources such as Patient, Encounter, Observation, Condition, MedicationRequest, and ServiceRequest
- FHIR JSON shape
- identifiers, coding systems, and provenance
- interoperability tradeoffs

Artifact:

- small synthetic FHIR-shaped dataset

## 3. Data Quality and Lineage

Learn:

- completeness
- validity
- duplication
- drift
- representativeness
- lineage

Artifact:

- data quality report with validation checks

## 4. Clinical-Style Model Evaluation

Learn:

- sensitivity, specificity, precision, recall, AUROC, calibration
- subgroup evaluation
- threshold selection
- error analysis
- explainability

Artifact:

- model evaluation report using synthetic data

## 5. Governance and Security

Learn:

- role-based access control
- encryption concepts
- audit logging
- privacy review
- risk assessment
- responsible AI documentation

Artifact:

- governance checklist and risk register

## 6. Production MLOps for Health AI

Learn:

- model registry
- deployment stages
- monitoring
- data and concept drift
- incident response
- rollback
- model retirement

Artifact:

- deployment runbook

## 7. RAG for Health Knowledge Systems

Learn:

- grounded citation behavior
- source quality
- retrieval evaluation
- refusal behavior
- safety and escalation patterns

Artifact:

- RAG prototype over public or synthetic guidance documents
